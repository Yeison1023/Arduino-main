Proceso Del Proyecto

Nuestra idea

¿Qué queremos construir?

Queremos construir un sistema de alarma antirrobo automatizado para habitaciones, diseñado para detectar accesos no autorizados en tiempo real y emitir alertas inmediatas (auditivas, visuales o digitales) que garanticen la seguridad del espacio.

¿Por qué escogimos esta idea?

Escogimos esta idea porque resuelve la necesidad real de proteger la privacidad y prevenir robos en espacios personales mediante un proyecto económico y viable, lo que nos permite aplicar de forma práctica conceptos clave de programación (como variables y condicionales) con la posibilidad de escalar el sistema a futuro hacia una solución más avanzada o inteligente.

¿Qué problema queremos solucionar?

El problema que queremos solucionar es la vulnerabilidad y la falta de seguridad en espacios privados, Muchas personas no cuentan con la tranquilidad de dejar sus espacios solos o de descansar sin el temor de que alguien entre sin su consentimiento. Al no disponer de sistemas de seguridad complejos o costosos, se genera una necesidad de contar con una solución accesible, automatizada e inmediata que alerte sobre cualquier intrusión en tiempo real.

Qué investigamos

¿Qué necesitamos aprender?

  • Lógica de programación: Mentalidad y estructura para resolver problemas y dar instrucciones a una computadora.
  • Variables y tipos de datos: Para almacenar estados (ej. let alarmaActivada = true;).
  • Estructuras condicionales: Uso de if, else if y else para evaluar las lecturas de los sensores.
  • Operadores lógicos y de comparación: Manejo de condiciones complejas (ej. &&, ||, ==, <).
  • Bucle principal y funciones: Estructurar el código para que escuche señales continuamente y ejecute acciones de respuesta.

¿Qué información encontramos?

Por ejemplo, para realizar el proyecto de manera inteligente, conectamos el Arduino a Wi-Fi; para eso necesitamos extensiones de hardware que sean adecuadas para lograrlo.

¿Cómo imaginamos el Robot?

Imaginamos la alarma como un dispositivo residencial de bajo costo, compacto y fácil de usar, diseñado específicamente para resguardar la privacidad de las habitaciones mediante una pequeña central de control con protoboard al lado del marco de la puerta, un sensor magnético en el acceso, un pulsador para conmutar manualmente entre los estados indicados por un LED verde (Armado/Desarmado), y un sistema de disuasión inmediata que activa un LED rojo parpadeante junto a un buzzer con tono de sirena (1000 Hz) en cuanto se detecta una apertura no autorizada.

¿Qué queremos que haga?

Queremos que el sistema detecte instantáneamente la apertura no autorizada de la puerta mediante el sensor magnético, active de inmediato una alerta sonoro-visual compuesta por la sirena del buzzer y el destello del LED rojo para ahuyentar al intruso, y permita al usuario armar o desarmar fácilmente la protección desde un pulsador manual con confirmación mediante el LED verde.

Materiales del Proyecto

Microcontrolador

Arduino Uno, ESP32 o Raspberry Pi Pico: Se encarga de procesar la lógica del código, leer las señales de los sensores y activar las alarmas.

Sensor de entrada

Sensor magnético o PIR (HC-SR501): Detecta la apertura no autorizada de la puerta o el movimiento en la habitación en tiempo real.

Actuadores de salida

Buzzer y LEDs (Rojo/Verde): Emite el tono de sirena de disuasión y muestra mediante luces el estado del sistema (Armado/Alerta).
