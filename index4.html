Componente Físico Pin Arduino Elemento Web / Software Función en el Sistema
Arduino Uno R3 — Lógica JavaScript Controlador principal del flujo de la alarma y temporizadores.
Sensor PIR HC-SR501 Pin Digital 2 Botón "Simular Intruso" Envía señal HIGH al detectar movimiento o radiación infrarroja.
Teclado Matricial 4x4 Pines 3, 4, 5, 6, 7, 9, 10, 11 Teclado Numérico Web Permite la entrada de la clave PIN para armar y desarmar el sistema.
Pantalla LCD 16x2 (I2C) A4 (SDA), A5 (SCL) Pantalla LCD Azul Simulado Muestra estados en tiempo real (ARMADO, ALERTA, INGRESO DE CLAVE).
Buzzer Piezoeléctrico Pin Digital 8 Sintetizador Web Audio API Genera la frecuencia de tono de la sirena cuando ocurre una intrusión.
LED Verde / Rojo Pins Digitales 12 y 13 Leds de Estado CSS Indicadores ópticos visuales (Verde = Seguro, Rojo Parpadeante = Alarma).
